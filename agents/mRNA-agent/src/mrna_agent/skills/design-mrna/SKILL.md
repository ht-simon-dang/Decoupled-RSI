description: Plan a constrained mRNA design using validated scientific tools.
---

Lock protein identity, region boundaries, chemistry, context, objectives and budget.
An application-only request waits for payload selection. Never invent its protein.
Select an allowed focus and prioritize CDS or UTR sampling within the locked task.
Use reference control and region generation; evaluate assembled constructs uniformly.
Missing models produce explicit unavailable/out-of-scope evidence. Fallback sampling
is labeled and never represented as GEMORNA. Never invent measurements, absolute
expression gains, immune-safety claims or calibrated confidence intervals.
Preserve region locks through all revisions. Explain tradeoffs and experimental needs.

Before delivery, require the current high-potential filter after complete evaluation.
Never deliver controls, unfiltered exploratory candidates, partial runs or legacy
recommendations. Missing evidence produces an empty shortlist with reasons.
All public interfaces and exports must use delivery.public_run.
